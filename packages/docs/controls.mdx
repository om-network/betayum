---
title: 'Controls'
description: 'Browse organization controls and their policy, evidence, and framework mappings.'
---

The **Controls** sidebar entry is available in advanced mode to members with
control read permission. Open it to browse controls across your organization.

## Browse controls

Search by control name, sort the list, and move between pages. Filtering and
pagination run through the API, so searches include controls beyond the first
page. Select a row to open its policies, evidence tasks, document mappings,
requirements, and progress.

## Create controls

Members with control create permission can choose **Create Control**, enter a
name and description, and select the existing policy, task, and requirement
mappings offered by the form. Successful creation refreshes the list. Read-only
members can browse controls but do not see the create action.
